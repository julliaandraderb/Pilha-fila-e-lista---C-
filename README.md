# Sistema Integrado de Estruturas de Dados

Projeto desenvolvido em **C#** para praticar o uso de estruturas de dados.

## Funcionalidades

- **Lista:** gerenciamento de tarefas.
- **Fila:** atendimento de pacientes.
- **Pilha:** histórico de navegação.

## Tecnologias

- C#
- .NET

## Objetivo

Praticar os conceitos de **List, Queue e Stack**, trabalhando com inserção, remoção e consulta de dados.

Desenvolvido por **Júllia Andrade** durante o curso de Desenvolvimento de Sistemas.
